# Краткая сводка по стеку проекта Luggify

## Общее описание

Luggify — веб-сервис для планирования поездок, формирования списков вещей, ведения чеклистов, совместной работы пользователей и интеграции с Telegram и AI-функциями.

## Клиентская часть

- **React** — основа пользовательского интерфейса веб-приложения.
- **Vite** — используется для сборки и локальной разработки фронтенда.
- **React Router** — используется для маршрутизации между страницами приложения.
- **react-datepicker** — используется для выбора диапазонов дат поездки.
- **react-select** — используется в формах выбора городов, параметров поездки и других пользовательских сценариях.
- **CSS** — используется для стилизации интерфейса, адаптивной верстки и отдельных экранов, включая AI-виджет и Telegram Mini App.

## Серверная часть

- **Python** — основной язык серверной разработки.
- **FastAPI** — используется для создания REST API, обработки клиентских запросов и объединения всей прикладной логики.
- **Uvicorn** — используется как ASGI-сервер для запуска FastAPI-приложения.
- **SQLAlchemy** — используется для работы с моделями данных и взаимодействия с базой данных.
- **Pydantic** — используется для валидации входных и выходных данных API.
- **HTTPX** — используется для обращения к внешним API и сервисам.
- **python-dotenv** — используется для загрузки конфигурации из `.env`.

## База данных и миграции

- **PostgreSQL** — основная реляционная база данных проекта.
- **asyncpg** — используется как асинхронный драйвер подключения к PostgreSQL.
- **Alembic** — используется для миграций схемы базы данных.
- **psycopg2-binary** — используется в служебных сценариях и совместимости при работе с PostgreSQL.

## Авторизация и безопасность

- **python-jose** — используется для работы с JWT-токенами.
- **passlib + bcrypt** — используются для хэширования и проверки паролей.

## Telegram-интеграция

- **Telegram Web Apps API** — используется для Telegram Mini App.
- **aiogram** — используется для разработки Telegram-бота и обработки пользовательских команд в Telegram.

## AI и интеллектуальные функции

- **Gemini API** — используется для AI-помощника, генерации рекомендаций, ответов по поездке и поддержки пользовательских запросов на естественном языке.
- **Детерминированный модуль обработки пользовательских команд** — используется для интерпретации типовых команд над чеклистом без необходимости полного генеративного ответа.

## Внешние сервисы

- **Open-Meteo** — используется для получения прогноза и исторических погодных данных.
- **Nominatim (OpenStreetMap)** — используется для поиска и геокодирования городов и локаций.
- **Google Places API (через RapidAPI)** — используется для поиска достопримечательностей, мест, заведений и других travel-объектов.

## Инфраструктура и запуск

- **Docker Compose** — используется для локального запуска клиентской части, серверной части, базы данных и Telegram-бота в едином окружении.

## Что где используется

- **Веб-клиент** — интерфейс поездки, чеклиста, профилей, AI-виджета и travel-разделов.
- **Сервер** — бизнес-логика, авторизация, работа с поездками, багажом, участниками, уведомлениями и интеграциями.
- **База данных** — хранение пользователей, поездок, чеклистов, багажа, маршрутов, уведомлений и связанных сущностей.
- **Telegram Mini App** — упрощенный доступ к поездке и чеклисту из Telegram.
- **Telegram-бот** — команды, быстрый доступ к поездкам, интерактивная работа с чеклистом и AI-сценариями.
- **AI-модуль** — ответы на вопросы пользователя, рекомендации по поездке, помощь с планом дня и работа с содержимым чеклиста.
